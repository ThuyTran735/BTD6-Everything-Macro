BTD6 Everything Macro v3.5.7 - UI visual audit
Tested: October 24, 2026

RESULT
4,037 automated assertions passed, plus desktop visual checks.
Tests ran in isolated copies, with synthetic data, using AutoHotkey v2.0.28
at the machine's current 120 DPI / 125% display scaling.
Repeated stress checks are counted as assertions, not as unique features.

FIXES
- Button captions and ? help icons remain visible after background repaint.
- All six button styles restore their normal/hover face after a press.
- Dark controls repair unwanted native light borders without forcing every
  layer to redraw on every hover or resize.
- Dropdowns use screen-pixel anchors, stay inside the current work area,
  reserve arrow space, and close when their owner is hidden or disabled.
- Unchanged list rows no longer rewrite their text and reset their fonts.
- Custom header hit areas respect display scaling; destroyed windows leave
  no stale header registration.
- Launcher mode changes, queue refreshes, and Builder layout changes update
  as a group rather than displaying intermediate empty arrangements.
- Reopening menus reuses their windows. Settings queue-button toggles retain
  the launcher window, its position, and its selected map/script.
- Settings status text no longer passes through a deliberately blank frame.
- Profile prompt cleanup no longer shows a hidden Profiles window briefly;
  returning to Profiles preserves its size and position.
- Logs closes with the other secondary menus.
- The run panel prepares its actual status before it appears. Queued retry
  details no longer wrap into a clipped heading, including long run counts.
- Builder monkey labels are transparent from their first displayed frame.
- Existing dark colors, heading/body fonts, button animations, and local
  UserData storage are preserved.

DESKTOP VISUAL CHECKS
Inspected the rendered launcher, Default strategy picker, Settings and
context help, UserData transfer, History, Retry/Recovery, Logs, queue manager,
queue job editor and its help, Profiles, mode picker, Auto Collection Event
launcher, finite/infinite count prompt, both run panels, setup and Expert
warnings, and Builder Monkeys/Actions/Export tabs plus contextual help.
Confirmed captions/help icons survive clicking, dropdown/list selections
refresh correctly, event mode omits queue controls, infinite count disables
its numeric field, and Builder help closes without growing the window.
Builder was also closed through its own close button without error output.

LIMITS
No game was started or controlled during the audit. Gameplay/fullscreen
transitions and every possible graphics-driver timing were not exercised.
The desktop tool supplies individual snapshots, not high-frame-rate video;
redraw/message and first-frame tests supplement those snapshots.
Screen-edge tests used the current monitor/work area. Other physical DPI
settings and mixed-DPI multi-monitor setups were not manually tested.
Builder resize stress used its real GUI layout/size callbacks; the desktop
click tool could not drag beyond the captured window boundary.
Passing these checks does not prove every possible transient flicker absent.

DATA AND DELIVERY
The release contains only the UI fixes, README highlights, and this report.
Maps and UserData are excluded from the update. Temporary test harnesses,
preview files, and test data are excluded from the changed-files package.
